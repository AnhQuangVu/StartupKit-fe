# STARTUPKIT – UI DESIGN RULE (CLEAN MINIMAL)

Framework: Next.js
Style: Clean Minimal – Inspired by Kickstarter

---

## 1. Design Philosophy

- Nội dung là trung tâm
- Typography dẫn dắt trải nghiệm
- Khoảng trắng nhiều
- Không hiệu ứng dư thừa

---

## 2. Layout System

Grid:
- 12 column grid
- Max width: 1200px
- Margin auto center

Section spacing:
- Padding top/bottom: 96px
- Section gap: 64px

Container:
- px-6 mobile
- px-12 desktop

---

## 3. Color System

Primary:
- Black: #111111
- White: #FFFFFF

Neutral:
- Gray 100: #F7F7F7
- Gray 200: #EAEAEA
- Gray 400: #999999

Accent:
- Vietnam Gold: #F4B400

Rules:
- Mỗi section chỉ tối đa 2 màu
- Không gradient
- Không background pattern

---

## 4. Typography Scale

H1: 48–56px
H2: 36–40px
H3: 24–28px
Body: 16–18px
Small: 14px

Line height:
- 1.5–1.7

Heading:
- Font weight: 600–700
- Không dùng all bold toàn trang

---

## 5. Spacing Rule

Card padding: 24px
Button padding: 12px 20px
Border radius: 8px
Card border: 1px solid #EAEAEA

Shadow:
- Hạn chế
- Nếu dùng thì shadow rất nhẹ

---

## 6. Landing Page Rule

Hero section:
- Background trắng
- Heading lớn
- Subtext nhỏ
- CTA rõ ràng

Không dùng:
- Slider tự động
- Video background
- Parallax nặng

Landing phải:
- Tối giản
- Nhiều khoảng trắng
- Tập trung conversion
